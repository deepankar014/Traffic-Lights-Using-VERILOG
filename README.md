# Traffic-Lights-Using-VERILOG
🚦 Traffic Light Controller using Verilog HDL

This project implements a Moore Finite State Machine (FSM) based traffic light controller for a two-road intersection using Verilog HDL. The controller generates Red, Yellow, and Green signals for each road in a safe and fixed sequence using counter-based timing. A synchronous design approach with proper reset handling ensures predictable operation.

The functionality of the design is verified using a Verilog testbench, and simulation waveforms are analyzed using EPWave to confirm correct state transitions and signal behavior. This project demonstrates fundamental RTL design concepts such as FSM modeling, sequential and combinational logic separation, clock-driven operation, and functional verification.
